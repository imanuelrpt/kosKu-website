# Gambar untuk README

Letakkan tangkapan layar (screenshot) di folder ini dengan nama berkas berikut
agar otomatis tampil pada `README.md` utama.

| Berkas | Isi yang disarankan |
| --- | --- |
| `dashboard-admin.png` | Dashboard admin: kartu statistik, grafik 6 bulan, daftar tagihan terlambat |
| `data-kamar.png` | Halaman Kamar beserta status dan harga sewa |
| `tagihan.png` | Daftar tagihan dengan filter status/bulan/tahun |
| `kwitansi.png` | Kwitansi pembayaran siap cetak |
| `laporan.png` | Laporan bulanan: pemasukan, pengeluaran, laba/rugi, grafik |
| `portal-penghuni.png` | Dashboard portal penghuni (kamar, tagihan, grafik pembayaran) |
| `cetak-tagihan.png` | Tagihan siap cetak / simpan PDF |

Panduan singkat:

- Format **PNG** (atau JPG), lebar sekitar **1200-1600 px** agar tajam di GitHub.
- Nama berkas harus sama persis (huruf kecil, tanda hubung) seperti tabel di atas.
- Setelah berkas ditambahkan, jalankan `git add docs/images` lalu commit dan push.

Selama berkas belum ada, GitHub akan menampilkan kotak gambar kosong dengan
teks alternatifnya. Itu normal dan akan hilang begitu gambar dimasukkan.
